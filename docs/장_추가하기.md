# 장 추가하기 (저자·관리자용)

장 하나는 `chapters/` 폴더의 마크다운 파일 하나입니다. 파일을 넣고 서버를 다시 띄우거나 페이지를 새로 고치면 장 목록에 나타납니다. 장 순서는 `id`의 숫자(ch02 → 2)로 정해지고, 같은 `part` 값끼리 묶여 보입니다.

## 1. 장 파일 만들기: `chapters/ch15.md`

````markdown
---
id: ch15
part: 5부 · 직무별 AX 에이전트 실습
title: 15장. 전사 공통 AX: 문서 검색과 근거 답변
summary: 장 카드에 보일 한두 문장
needs: OPENAI_API_KEY
---
첫 문단은 장 설명입니다. 마크다운 제목(##, ###), 문단, `코드`, **굵게**, 목록(-)을 쓸 수 있습니다.

### 15.2.1 절 제목

```py 원고
# 책에 실린 코드를 그대로 붙입니다
print("hello")
```

```py 보조
#! note: 셀 위에 보일 안내 한 줄
# 책 본문에는 없지만 실행에 필요한 준비 코드
```

```py 읽기전용
#! note: 그대로는 실행되지 않는 이유
# 화면에 보여 주기만 하고 실행 버튼이 없습니다
```
````

### 머리말 항목

| 항목 | 뜻 | 생략하면 |
|---|---|---|
| `id` | 장 ID. 파일 이름과 같게 씁니다(`ch15`) | 필수 |
| `part` | 장 목록에서 묶을 부 이름 | 필수 |
| `title` | 장 제목 | 필수 |
| `summary` | 장 카드 설명 | 빈칸 |
| `needs` | 필요한 키. 화면에 표시하고, 키가 없으면 안내를 띄웁니다 | 없음 |
| `workdir` | 셀이 실행되는 폴더 | `work/<id>` |

### 셀 종류와 지시 줄

코드 블록 언어 뒤에 `원고`·`보조`·`읽기전용` 중 하나를 적습니다. 코드 맨 앞의 `#!` 줄은 지시로 읽고 화면의 코드에는 넣지 않습니다.

| 지시 | 뜻 |
|---|---|
| `#! note: ...` | 셀 위에 안내를 보여 줍니다. |
| `#! fake: ...` | 가짜 모델 모드에서 이 한 줄을 대신 실행합니다(예: `sh("python ../live_check.py --fake --jobs receipt")`). |
| `#! expect: error` | 오류가 나는 것이 정상인 셀입니다. 전체 실행이 여기서 멈추지 않습니다. |

셀 안에서는 `sh("python -m pytest -q")`처럼 명령을 실행할 수 있습니다. `python`은 실행기의 파이썬으로 바뀌고, 출력은 셀 결과로 보입니다.

## 2. 장에서 쓰는 파일 넣기: `chapters/ch15/`

CSV, MCP 서버 스크립트처럼 셀이 읽는 파일은 `chapters/<id>/` 폴더에 둡니다. 셀을 처음 실행할 때 작업 폴더(`work/<id>/`)로 복사되므로, 셀 코드에서는 `"sales.csv"`처럼 파일 이름만 쓰면 됩니다.

공통 골격(14장) 위에 올리는 실습이라면 `workdir: axcore_proj`로 두고, job 코드는 `axcore_proj/jobs/<job>/`, 데이터는 `axcore_proj/samples/<job>/`, 테스트는 `axcore_proj/tests/`에 넣습니다. 17·18장 파일을 참고하세요.

## 3. 새 패키지가 필요하면

`requirements.txt`에 버전을 고정해 추가합니다. 독자가 실행기를 다시 띄우면 바뀐 것을 알아채고 한 번 더 설치합니다.

## 4. 점검

```bash
python tools/check_examples.py ch15            # 가짜 모델로 모든 셀 실행
python tools/check_examples.py --real ch15     # 실제 모델로 실행(.env 키 사용)
python tools/check_examples.py -v ch15         # 셀 출력까지 보기
```

가짜 모델은 도구를 한 번씩 부르고 결과를 옮겨 답하는 단순한 모델입니다. 흐름 점검용이므로, 배포 전에는 `--real`로 한 번 돌려 실제 결과가 원고의 실행 결과와 맞는지 확인합니다.
