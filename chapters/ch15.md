```py 보조
#! note: 합성 문서 7개를 다시 만듭니다. 이미 들어 있으므로 건너뛰어도 됩니다.

```

### 15.3.2 모든 파일을 줄 단위 텍스트로 읽기

```py 보조
#! note: PPT를 markitdown으로 바꾼 줄 목록의 앞부분입니다. 도구와 검증기가 같은 함수로 읽습니다.
from jobs.folder_search import folder as fs
from jobs.folder_search.spec import SAMPLE_DIR

for i, line in enumerate(fs.read_lines(SAMPLE_DIR, "전략발표_2027.pptx")[:8], 1):
    print(f"L{i}: {line}")
```
